# Tennis Game Analytics using SportRadar API

## Overview

Tennis Game Analytics is a data-driven analytics platform that collects real-time tennis data from the SportRadar API and transforms it into meaningful insights for player and match performance analysis.

## Features

- Real-time tennis data extraction using SportRadar API
- JSON data processing and transformation
- Player performance analytics
- Match statistics visualization
- SQL database integration
- Interactive analytics dashboard

## Tech Stack

- Python
- Pandas
- MySQL
- SportRadar API
- JSON

## Project Workflow

1. Fetch tennis data from SportRadar API
2. Process and clean JSON datasets
3. Store structured data in MySQL
4. Generate analytics and statistics
5. Visualize insights through dashboards
